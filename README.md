Live Demo 👉 https://dailynewsapp-by-sathvika.netlify.app
📌 Project Overview
Daily News App is a responsive React-based web application that fetches real-time global news using the NewsAPI and allows users to explore trending topics by category. Designed with clean UI and interactive features, it enhances user experience and delivers summaries to help digest long articles faster.

💡 Features
🔍 Category Filters – Browse news by Tech, Sports, Health, Business, and more

📄 Article Cards – Clickable cards that open full articles in a new tabby clicking on Read more buttons

✂️ Summarized Descriptions – Each article includes a brief summary to preview content

🌙 Dark Mode – Switch between light/dark themes for better readability

🔄 Live Data Fetching – Fetches news from NewsAPI in real time including current date and time

🧼 Responsive Design – Optimized for mobile, tablet, and desktop
